# FloatTrade Demo

一个面向新手投资者和上班族的股票交易界面 demo。项目目标不是复刻传统券商软件的复杂信息密度，而是把“看行情、建模拟仓、设置风险计划、快速隐藏”做成更轻量、更容易理解的交易工作台。

在线预览：

[https://chasedream7.github.io/floattrade-demo/](https://chasedream7.github.io/floattrade-demo/)

## 项目背景

产品经理笔试题要求：设计一个股票交易界面 demo，覆盖手机端和网页端，可以交付 HTML 格式，并解释功能设计原因，强调产品差异化和微创新。

FloatTrade 的产品假设是：很多新手用户并不缺行情信息，而是被传统交易软件的信息噪音、专业术语和复杂入口劝退；另一类用户是在工作或学习场景中轻量关注市场，不希望频繁切换完整交易软件。因此 demo 采用模块化交易台和悬浮行情窗，让用户在低打扰场景下完成观察、模拟交易和风险管理。

## 产品定位

FloatTrade 是一个“新手友好的模拟交易工作台”。

核心用户：

- 刚开始学习股票和 ETF 的新手用户。
- 希望先用模拟仓练习交易纪律的用户。
- 工作中只想轻量查看行情和预警的上班族。
- 需要把交易计划、止损止盈和复盘流程可视化的用户。

核心价值：

- 降低新手理解成本：把交易拆成市场、入场、仓位、止损、止盈五个决策点。
- 降低操作打扰：通过悬浮窗和 Quick hide 快速隐藏交易界面。
- 降低真实资金风险：默认使用 paper trading 模拟仓。
- 降低视觉误判：普通 UI 使用灰白透明色，红绿只用于行情和风险信号。

## Demo 范围

当前 demo 是静态前端原型，使用模拟数据，不连接真实券商账户，不产生真实交易。

已覆盖市场：

- A 股
- 美股
- ETF

已移除不相关市场展示，例如 CAD。

## 核心功能

### 1. 模块化交易工作台

顶部 tab 支持打开、聚焦和关闭模块。用户可以按自己的交易习惯组合工作区，例如只保留 Chart、Order entry、Alert、Risk line，也可以展开 Account、Level 2、Option chain、News 等高级模块。

设计原因：

传统交易软件默认把大量模块堆在一起，新手很难判断哪些是当前任务必要信息。模块化设计让用户从“完成一笔有计划的模拟交易”出发，只打开当前需要的模块。

### 2. 悬浮行情窗

右下角提供可拖拽的悬浮窗口，展示当前标的价格、涨跌幅、成交量、预警价和迷你走势图。支持最小化和关闭。

设计原因：

适合工作或学习场景中轻量关注行情，减少频繁切换应用的成本。悬浮窗只展示核心信息，不承载复杂下单操作，避免打扰当前任务。

### 3. Quick hide 隐蔽模式

一键隐藏交易台，页面切换成类似工作概览的低敏状态，并保留恢复入口。

设计原因：

这是面向“摸鱼族”的差异化设计。它不是鼓励过度交易，而是承认用户真实使用场景：在非专注交易环境中，界面需要能快速降噪和隐藏。

### 4. 模拟仓下单

Order entry 支持选择标的、设置方向、仓位比例、入场价、止损价、止盈价和备注。提交后会更新模拟持仓和现金。

设计原因：

对新手来说，最重要的不是快速下单，而是训练交易计划。表单强制暴露止损、止盈、仓位等字段，帮助用户在入场前先想清楚风险。

### 5. 风险线和交易清单

Risk line 展示仓位、止损距离和回撤压力；Checklist 用勾选项帮助用户确认是否已有交易理由、止损、止盈和复盘记录。

设计原因：

把交易纪律产品化。新手常见问题是“先买了再想怎么卖”，所以 demo 把风险检查前置到下单前。

### 6. Level 2 盘口

Level 2 保留盘口语义色：Bid 使用冷色，Ask 使用玫红，深度图左右两侧也对应买卖盘分层。

设计原因：

虽然整体 UI 使用灰白透明，盘口本身仍需要颜色来区分买卖方向。这里的颜色语义与股票涨跌分开，避免用户把“买盘/卖盘”误解成“上涨/下跌”。

### 7. 市场感知涨跌颜色

不同市场采用不同涨跌颜色规则：

- A 股 / ETF：红涨绿跌。
- 美股：绿涨红跌。
- Level 2：Bid/Ask 使用盘口专用色，不复用涨跌色。
- 普通按钮、tab、卡片选中态：使用灰白透明，不使用蓝色或红绿。

设计原因：

跨市场交易时，颜色习惯会影响用户判断。A 股和美股的红绿语义相反，如果所有市场共用一套颜色，会造成误读。普通 UI 不使用蓝色，是为了避免蓝色同时承担“功能高亮”和“行情信号”的双重含义。

### 8. Strategy lab

内置三类策略卡片：均线回踩、放量突破、ETF 定投节奏，并展示年化收益、最大回撤和信号次数。

设计原因：

为后续量化能力预留入口。对于新手，策略不应直接变成自动交易按钮，而应先以“模板”和“回测结果”的形式帮助用户理解交易逻辑。

可扩展方向：

- 接入 vn.py 做策略回测和信号生成。
- 支持用户保存策略模板。
- 将策略信号转成模拟仓计划。
- 增加风险约束，例如单笔最大亏损、每日最大交易次数。

## 交易系统五要素

| 要素 | Demo 中的设计 |
| --- | --- |
| 交易的市场范围 | 顶部 Market switcher 支持 A 股、美股、ETF |
| 何时进入市场 | Chart、Level 2、News、Strategy lab 提供入场判断信息 |
| 交易多少 | Order entry 通过仓位比例控制下单规模 |
| 何时止损 | 下单表单内置 Stop loss 字段，Risk line 展示止损距离 |
| 何时止盈 | 下单表单内置 Take profit 字段，并与交易计划绑定 |

## 典型用户流程

1. 选择市场：A 股、美股或 ETF。
2. 从 Watchlist 或搜索区域选择标的。
3. 查看 Chart、Level 2 和行情摘要。
4. 在 Checklist 中确认交易理由、止损和止盈。
5. 在 Order entry 中设置仓位、入场价、止损价和止盈价。
6. 提交 paper order，进入模拟仓。
7. 通过 Alert 和悬浮窗持续跟踪核心价格变化。
8. 在 Review 中记录交易结果和复盘结论。

## 差异化与微创新

- 新手模式：把交易从复杂软件操作拆成五个清晰决策点。
- 悬浮行情窗：低打扰地关注价格、成交量和预警价。
- Quick hide：适配工作场景，快速隐藏交易台。
- 模块可关闭：用户可以自己决定工作区复杂度。
- 市场感知颜色：A 股、美股、ETF 使用各自更符合用户习惯的涨跌颜色。
- 盘口颜色独立：Level 2 买卖盘颜色与涨跌色分离，减少语义混淆。
- Paper trading 优先：先训练交易计划，再考虑真实交易。

## 技术实现

项目为纯静态前端 demo：

- `index.html`：页面结构和交易模块。
- `styles.css`：深色交易台视觉、响应式布局、盘口和行情颜色系统。
- `script.js`：模拟数据、市场切换、图表绘制、模块开关、模拟下单、预警和悬浮窗交互。

未使用构建工具，便于直接提交 HTML 作业或部署到 GitHub Pages。

## 本地运行

在项目目录运行：

```bash
python3 -m http.server 5089 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:5089/
```

也可以直接打开 `index.html` 查看基础页面，但本地服务更接近线上部署效果。
